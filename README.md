# KarmaCompass

KarmaCompass enables distributed, scalable automation through an event-driven architecture, cloud-agnostic deployment via a centralized Manager and Scheduler framework.

KarmaCompass is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- KarmaCompass enables distributed, scalable automation
- through an event-driven architecture, cloud-agnostic
- deployment via a centralized Manager

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/KarmaCompass.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

KarmaCompass is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
